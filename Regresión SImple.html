Regresión Lineal Simple

6.1 El Modelo

La regresión lineal simple es un método estadístico para modelar la relación entre dos variables: una variable dependiente y y una variable independiente x. El modelo se expresa mediante: 

yᵢ = β₀ + β₁ xᵢ + εᵢ,   i = 1, 2, …, n

Donde:

  • yᵢ: valor observado de la variable dependiente.
  • xᵢ: valor de la variable independiente (predictora).
  • β₀: intercepto (o término constante).
  • β₁: pendiente, que indica el cambio en y ante un cambio unitario en x.
  • εᵢ: error aleatorio o perturbación.

Se denomina "simple" porque solo se utiliza una variable predictora y "lineal" porque el modelo es lineal en los parámetros β₀ y β₁ (incluso modelos con x² pueden ser lineales en los parámetros). Además, se hacen las siguientes suposiciones:

  1. Esperanza del error cero: E(εᵢ) = 0 para todo i, lo que implica E(yᵢ) = β₀ + β₁ xᵢ.
  2. Varianza constante (homocedasticidad): var(εᵢ) = σ² para todo i.
  3. No correlación entre errores: cov(εᵢ, εⱼ) = 0 para i ≠ j.

En este modelo se asume que los yᵢ y los errores εᵢ son variables aleatorias, mientras que los xᵢ son valores fijos y conocidos.

6.2 Estimación de β₀, β₁ y σ²

A partir de una muestra de n observaciones y₁, y₂, …, yₙ y sus correspondientes valores fijos x₁, x₂, …, xₙ, se estima el modelo usando el método de los mínimos cuadrados. Este método busca minimizar la suma de los cuadrados de las diferencias entre los valores observados y los predichos: 

SSE = ∑ (yᵢ – ŷᵢ)² = ∑ (yᵢ – (β̂₀ + β̂₁ xᵢ))²,   i = 1, 2, …, n

Al diferenciar SSE respecto a β₀ y β₁ y resolver el sistema de ecuaciones (ecuaciones normales), se obtiene: 

β̂₁ = [∑ (xᵢ – x̄)(yᵢ – ȳ)] / [∑ (xᵢ – x̄)²]
β̂₀ = ȳ – β̂₁ x̄

Donde x̄ y ȳ son las medias muestrales de x y y, respectivamente.

La varianza del error σ² se estima por: 

s² = SSE / (n – 2) = ∑ (yᵢ – ŷᵢ)² / (n – 2)

Se utiliza n – 2 en el denominador porque se han estimado dos parámetros (β₀ y β₁).

6.3 Prueba de Hipótesis e Intervalo de Confianza para β₁

Generalmente se desea determinar si existe una relación lineal significativa entre y y x. Para ello se prueba la hipótesis nula: 

H₀: β₁ = 0

Bajo el supuesto de normalidad de los errores (εᵢ ~ N(0, σ²)), el estimador β̂₁ es una variable aleatoria con distribución normal y varianza σ² / ∑ (xᵢ – x̄)². Se define el estadístico t: 

t = β̂₁ / [s / √(∑ (xᵢ – x̄)²)]

Este estadístico sigue una distribución t con n – 2 grados de libertad bajo H₀. Se rechaza H₀ si |t| es mayor que el valor crítico t(α/2, n – 2) o, de forma equivalente, si el valor p es menor que el nivel de significación α.

Asimismo, un intervalo de confianza al 100(1 – α)% para β₁ es: 

β̂₁ ± t(α/2, n – 2) · [s / √(∑ (xᵢ – x̄)²)]

6.4 Coeficiente de Determinación

El coeficiente de determinación (r²) mide la proporción de la variación total de y que es explicada por la regresión sobre x. Se define como: 

r² = SSR / SST = ∑ (ŷᵢ – ȳ)² / ∑ (yᵢ – ȳ)²

Donde:

  • SSR es la suma de cuadrados de la regresión (variación explicada).
  • SST es la suma total de cuadrados (variación total de y).

Además, r² es igual al cuadrado del coeficiente de correlación muestral r entre x y y, donde: 

r = [∑ (xᵢ – x̄)(yᵢ – ȳ)] / √[∑ (xᵢ – x̄)² · ∑ (yᵢ – ȳ)²]

Un valor de r² cercano a 1 indica que el modelo explica la mayor parte de la variación de y, mientras que un valor cercano a 0 indica un mal ajuste.

Ejemplos Ilustrativos

Ejemplo 6.2: Se analiza la relación entre las notas de examen (y) y el puntaje promedio de tareas (x) para 18 estudiantes. Aplicando las fórmulas de mínimos cuadrados se obtiene la ecuación de regresión: 

ŷ = 10.73 + 0.8726x

Aquí, 0.8726 representa el cambio esperado en el puntaje del examen por cada unidad de aumento en el puntaje de tareas, mientras que 10.73 es el valor estimado de y cuando x = 0.

Ejemplo 6.3: Para los mismos datos se prueba la hipótesis H₀: β₁ = 0. Se calcula el estadístico t: 

t =  β̂₁ / [s / √(∑ (xᵢ – x̄)²)] ≈ 8.80

Como este valor es mucho mayor que el valor crítico (por ejemplo, t₀.₀₂₅,₁₆ ≈ 2.12), se rechaza H₀ y se concluye que existe una relación lineal significativa entre las variables.

Ejemplo 6.4: Se calcula el coeficiente de determinación: 

r² = SSR / SST ≈ 0.8288

Esto indica que aproximadamente el 82.88% de la variación en las notas del examen se explica por el puntaje de tareas.

Conclusión

La regresión lineal simple es una herramienta fundamental para modelar y analizar la relación lineal entre dos variables. Con la estimación de parámetros mediante el método de los mínimos cuadrados, la realización de pruebas de hipótesis y la evaluación del ajuste a través del coeficiente de determinación, se pueden obtener importantes inferencias y predicciones en contextos diversos.
